參考書目樹狀結構與人名、書名關聯規劃（2026-11-01）

依據：開發鐵律第十三節（作者 2026-11-01 定）。本檔是規劃，尚未動工。

一、樹狀結構（網站導覽）

  1. 致謝（最頂端）
  2. 作者親寫的致謝文（受訪者、協助者、廟方、圖書館）。
  3. 「本站倚重的著作」：依引用次數自動列出前 20 本，連到書目頁。
  4. 引用書目
  5. 專書
  6. 方志與古籍（清代方志、臺灣文獻叢刊等）
  7. 期刊文章（南瀛文獻、臺南文化、臺灣風物……，文章各自一條，掛在期刊底下）
  8. 學位論文
  9. 官方報告（台江處委託報告 57 份等）
  10. 公文、判決、檔案
  11. 地圖
  12. 影音（公視《我們的島》等）
  13. 網路資料（只收主要網站；新聞另成「新聞線」，見第五節）
  14. 每一條書目頁的內容
  15. 書目資料：書名、作者／編者／譯者、出版者、年份、ISBN、國圖與國臺圖索書號。
  16. 作者：連到人物詞條（沒有就建，上網查身分與經歷，查不到標「待補」）。
  17. 著作權狀態：公共財／受保護到哪一年／不受保護（來自 統整/31_著作權/書目著作權狀態.json）。
  18. 本站哪些頁面引用了它（程式自動反查，含頁碼）。
  19. 本書記載的人物（程式自動反查，見第二節）。
  20. 取得方式：線上全文網址或館藏位置。

二、人名與書名怎麼關聯

三種關係，資料都只寫一次，反向由程式推：

  1. 作者關係（人 → 書）
  2. 寫在書目頁：authors: [{ slug: "lu-jiaxing", role: "著" }]，role 可為 著、編、譯、校註、攝影。
  3. 人物頁自動出現「著作」一節，列出他寫的書。
  4. 記載關係（書 → 書中出現的人）
  5. 寫在人物頁的 references：每條出處加 sourceId（書目頁的 slug）與 pages（頁碼）。
  6. 人物頁的生平句照現在寫法標 [R001]，出處欄顯示「記載於《書名》頁 x」並連到書目頁。
  7. 書目頁自動出現「本書記載的人物」。
  8. 引用關係（任何頁面 → 書）
  9. 所有頁面的 references 一樣加 sourceId 與 pages。
  10. 書目頁自動列出「本站引用本書的頁面」。

這樣一個人如果同時是作者、又被別本書記載（例如黃典權：寫了論戰文章，也出現在別人的著作裡），兩個角色會分開顯示，不會混在一起。

三、資料結構（工程）

  1. 新增實體類型 source（書目），放在 content/entities/，slug 例：src-lu-jiaxing-1965-luermen。
  2. frontmatter 新欄位
  3. sourceKind：book／gazetteer／article／thesis／report／document／map／av／web。
  4. authors、publisher、year、isbn、callNumbers: { ncl, ntl }。
  5. partOf：期刊文章指向期刊的書目頁。
  6. copyright: { status, expires, holder, basis }。
  7. access：線上全文網址或館藏說明。
  8. references 的 schema（entityReferenceSchema 與 content.ts 的 referenceSchema）各加兩個選填欄位：sourceId、pages。舊的 source 文字欄保留，作為顯示與備援。
  9. 建置時驗證：sourceId 必須是存在的 source 實體；作者 slug 必須是存在的 person 實體。

四、做法與順序

  1. 第一步：schema、書目頁版型、致謝頁、引用書目總表頁；先手工建 20 本最常被引用的書（台江處報告、《臺灣縣志》、《土城子簡介》、《南瀛刈香誌》等）試版。
  2. 第二步：寫比對腳本，把全站既有 references 的 source 文字自動對到書目頁，產生 sourceId 建議清單；人工（或 agent）抽查後套用。
  3. 第三步：交給 agent 批次建其餘書目頁（約 170 筆）與缺的作者人物詞條，作者資訊上網查。
  4. 第四步：人物詞條補 sourceId、pages，讓「本書記載的人物」長出來。
  5. 英文版同步（書名保留中文原名，附英譯）。

五、作者決定（2026-11-01）

  1. 致謝：寫全部的人與機構。
  2. 範圍：所有被引用的作者、編者、譯者、攝影者；出版與典藏機構（台江處、臺南市文化局、國史館、臺灣文獻館、國圖、國臺圖、中研院等）；廟方與地方團體；受訪與提供口述的人。
  3. 作者與機構名單由書目頁與引用資料自動彙整，作者另寫一段親筆致謝放在最前面。
  4. 口述者照本站口述規則處理（原本不具名的維持不具名，以「某某里居民」等方式致謝）。
  5. 新聞：獨立成一條「新聞線」，依時間排列，不放進引用書目樹，也不建立因果引用關係。
  6. 每則新聞記：日期、媒體、標題、記者、網址（含存檔）、相關實體標籤。
  7. 頁面引用新聞時照現在的出處寫法；新聞線本身只是依時間整理的索引。
  8. 書目頁公開顯示著作權狀態，作為書目介紹的其中一個分類（公共財／受保護到哪一年／不受保護的公文類），不另做獨立頁。
